# HU-D2-1: Recibir resultados automáticamente desde el LIMS

| Campo | Valor |
|---|---|
| **ID** | HU-D2-1 |
| **Actividad** | D2. Integración automática con el laboratorio (LIMS) |
| **Release** | R3 – Control y automatización |
| **WSJF de la actividad** | 0.85 |
| **Dependencias** | HU-D1-1 |
| **Estado** | Por refinar |

## Historia

**Como** analista de laboratorio, **quiero** que los resultados validados en el LIMS se envíen automáticamente al sistema, **para** eliminar la carga manual de Excel.

## Criterios de aceptación

- **CA1:** La sincronización es programada o en tiempo real.
- **CA2:** Si un código de muestra no existe, se registra como error de integración.
