# HU-D1-2: Corregir la ley de una muestra

| Campo | Valor |
|---|---|
| **ID** | HU-D1-2 |
| **Actividad** | D1. Ingreso de leyes de laboratorio (manual o Excel) |
| **Release** | R1 – MVP de trazabilidad de leyes |
| **WSJF de la actividad** | 8.67 |
| **Dependencias** | HU-D1-1 |
| **Estado** | Por refinar |

## Historia

**Como** jefe de laboratorio, **quiero** corregir manualmente la ley de una muestra (por ejemplo, tras un reensayo), **para** mantener la información correcta.

## Criterios de aceptación

- **CA1:** La corrección exige un motivo.
- **CA2:** Se conserva el valor anterior en el historial.
- **CA3:** Al corregir, la ley de la pila se recalcula automáticamente.
