# HU-J1: Capturar automáticamente el peso del volquete

| Campo | Valor |
|---|---|
| **ID** | HU-J1 |
| **Actividad** | J. Integración con la balanza |
| **Release** | R3 – Control y automatización |
| **WSJF de la actividad** | 1.38 |
| **Dependencias** | HU-B1 |
| **Estado** | Por refinar |

## Historia

**Como** operador de cancha, **quiero** que el peso del volquete se capture automáticamente desde la balanza, **para** evitar errores de digitación.

## Criterios de aceptación

- **CA1:** El peso se asocia al viaje por placa y hora.
- **CA2:** Si falla la integración, se permite el ingreso manual con justificación.
