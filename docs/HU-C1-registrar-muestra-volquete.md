## Historia

**Como** muestrero, **quiero** registrar la muestra tomada de cada volquete con un código único, **para** asegurar que cada muestra corresponda a un solo viaje.

## Criterios de aceptación

- **CA1:** El código de muestra se genera automáticamente y es único.
- **CA2:** Un volquete solo puede tener una muestra principal.
- **CA3:** Registra fecha/hora de muestreo y nombre del muestrero.
