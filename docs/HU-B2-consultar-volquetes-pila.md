# HU-B2: Consultar los volquetes de una pila

| Campo | Valor |
|---|---|
| **ID** | HU-B2 |
| **Actividad** | B. Registro de volquetes asociados a un polígono o pila |
| **Release** | R1 – MVP de trazabilidad de leyes |
| **WSJF de la actividad** | 6.80 |
| **Dependencias** | HU-B1 |
| **Estado** | Por refinar |

## Historia

**Como** geólogo de control de leyes, **quiero** ver el listado de volquetes asociados a una pila, **para** verificar el tonelaje acumulado y detectar errores de asignación.

## Criterios de aceptación

- **CA1:** El listado muestra placa, fecha, tonelaje y estado de la muestra.
- **CA2:** Muestra el tonelaje total acumulado de la pila.
- **CA3:** Se puede reasignar un volquete a otra pila, con justificación obligatoria.
