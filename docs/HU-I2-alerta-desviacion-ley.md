# HU-I2: Alertar desviaciones de ley

| Campo | Valor |
|---|---|
| **ID** | HU-I2 |
| **Actividad** | I. Validaciones y alertas |
| **Release** | R3 – Control y automatización |
| **WSJF de la actividad** | 3.60 |
| **Dependencias** | HU-D1-1 |
| **Estado** | Por refinar |

## Historia

**Como** jefe de geología, **quiero** que el sistema alerte cuando la ley de una muestra se desvíe significativamente del promedio de su labor, **para** detectar errores de muestreo o de asignación.

## Criterios de aceptación

- **CA1:** El umbral de desviación (en %) se puede configurar.
- **CA2:** La muestra queda marcada como "Observada" hasta que alguien la revise.
