# HU-I1: Alertar volquetes sin muestra o sin resultado

| Campo | Valor |
|---|---|
| **ID** | HU-I1 |
| **Actividad** | I. Validaciones y alertas |
| **Release** | R3 – Control y automatización |
| **WSJF de la actividad** | 3.60 |
| **Dependencias** | HU-C1, HU-D1-1 |
| **Estado** | Por refinar |

## Historia

**Como** geólogo de control de leyes, **quiero** recibir alertas de volquetes sin muestra o con resultado pendiente por más de X horas, **para** no cerrar pilas con información incompleta.

## Criterios de aceptación

- **CA1:** El plazo X se puede configurar.
- **CA2:** La alerta aparece en una bandeja y opcionalmente se envía por correo.
